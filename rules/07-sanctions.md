# 7. Санкции и тревоги

| Пункт | Правило |
|:-----:|---------|
| **7.1** | **Запрещено** объявлять тревоги по городам, не относящимся к вашей зоне ответственности. Тревога — строго по своему городу и только при наличии оснований. |
| **7.2** | Санкции применяются только в рамках регламента и только при реальном нарушении. Санкция не может быть демонстрацией власти. |
| **7.3** | Перед санкцией (если ситуация не требует немедленного реагирования) убедитесь в наличии нарушения и зафиксируйте основание. |
| **7.4** | **Запрещено** применять санкции из личной неприязни, в состоянии раздражения или в ответ на личную обиду. Спорные решения фиксируются и могут быть пересмотрены. |

---

> ### 🚨 Тревога — это ответственность
>
> Тревога по чужому городу = дезинформация тысяч людей.
> Объявляйте только по своему городу и только при реальной необходимости.
